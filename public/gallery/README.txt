ФОТО ИЗ ГАЛЕРЕИ ЯНДЕКС.КАРТ
===========================

Скачайте нужные фото/видео из галереи пиццерии на Яндекс.Картах:
https://yandex.com/maps/org/pizzagram/181221150144/gallery/

и положите их в эту папку (public/gallery/) СТРОГО с такими именами —
сайт подхватит их автоматически.

Блок «О нас» — коллаж из 4 фото:
  about-1.jpg  — большое фото слева (главное: процесс / шеф / печь)
  about-2.jpg  — высокое фото справа сверху
  about-3.jpg  — высокое фото справа снизу
  about-4.jpg  — широкое фото снизу (зал / интерьер)

Блок «Отзывы» — лента из 6 квадратных фото:
  photo-1.jpg ... photo-6.jpg

Требования к файлам:
  • формат — .jpg (или .png/.webp, но тогда поменяйте расширение в коде —
    скажите мне, и я поправлю);
  • для коллажа «О нас» лучше горизонтальные/крупные снимки,
    для ленты «Отзывы» — любые, они кадрируются в квадрат;
  • размер по длинной стороне — от 1000 px.

ВИДЕО: если хотите видео в каком-то блоке коллажа «О нас» — пришлите файл
.mp4 и скажите, в какой слот (about-1…about-4). Я заменю этот блок на
зацикленное видео без звука.
